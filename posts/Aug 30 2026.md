### My First Post

I'll be explaining each part of my home lab, how they work together, and essentially what I have done so far. I have been working on this since May 2026. There are some major changed I have done to this through the months that I would like to share
I have created 3 main services for BTcloud. These are:
- Talk
- Cloud
- AI

Those are the 3 most important services to me. I created BTcloud because I struggled to find a good source that is private, easy to use, and genuinely works that does the 3 main services I needed. After reaching nowhere, I just decided to make it myself. The list that follows are some goals I wanted in this project. (this applies to all 3 services):
1. Private (no information goes near any big-tech service)
2. Local (all information is stored on my hardware)
3. Secure (ensure that everything done on BTcloud stays on BTcloud)

Here are some goals that are specific to each service:
> Talk: This has to be secure, e2ee, and have no/low amounts of limits on screensharing quality or anything that has to do with the speed of user's connections. User's hardware should always be the limit.

> Cloud Drive: This has to be easy to use, easy to share with people, and familier. This means something like Google Drive of Microsoft OneDrive

> AI: Instead of just making slop, I wanted to make AI useful in a way that could fit my 3 main goals. Making something similar to JARVIS is what many people think when running a local private AI model, but its not the best idea in my opinion. I focused on making sure that tool usage and the UI it self was proper.

BTcloud first started off as a gimmick. I did not find it useful in any way, the texting server I chose was awful. However, I had created something, somewhere to start. From there forth, I decided to make BTcloud mainly private, putting auth walls wherever possible and not advertising services that were private. These include my photos server and my minecraft server.
My first iteration of BTcloud started with AI. I was heavily invested in creating LLMs and trying to build my own AI service that I can use with to effectivly replace ChatGPT and Claude for many general jobs and some advanced jobs. I started by using Ollama with some Gemma and Qwen models. At this stage, things were basic. You could chat with the model, get some information, but it was mostly basic information. Nothing was serious.
